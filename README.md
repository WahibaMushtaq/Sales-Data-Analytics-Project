
# Sales Data Analytics Project

## Project Overview
This is an end-to-end Sales Data Analytics project using Python, SQL, and Power BI.

## Tools & Technologies
- Python
- Jupyter Notebook
- SQL / MySQL
- Power BI

## Project Workflow
1. Data analysis and processing using Python.
2. SQL queries and table operations using MySQL.
3. Data visualization and dashboard development using Power BI.

## Power BI Dashboard
The dashboard provides insights into:
- Total Sales
- Total Profit
- Monthly Sales Growth
- Regional Sales Performance
- Product-wise Sales

## Project Files
- `Sales_Analysis.ipynb` – Jupyter Notebook containing Python and SQL work.
- `Power-BI-Dashboard/` – Power BI report and dashboard screenshot.
